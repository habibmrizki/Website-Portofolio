# Space Portfolio - Habib M Rizki

Welcome to the Space Portfolio of Habib M Rizki! This is a modern, interactive, and visually stunning personal portfolio website built with cutting-edge web technologies, featuring a captivating space theme.

## 🚀 Features

*   **Immersive Space Theme**: Dark mode design with vibrant accents, starry backgrounds, and fluid particle animations.
*   **3D Elements**: Interactive 3D objects and scenes powered by Three.js and React Three Fiber.
*   **Smooth Animations**: Fluid page transitions and scroll-triggered animations using Framer Motion and AOS (Animate On Scroll).
*   **Responsive Design**: Fully responsive layout that looks great on desktops, tablets, and mobile devices.
*   **Modern Tech Stack**: Built with Next.js 16 (App Router), React 19, and styled with Tailwind CSS v4.
*   **Backend Integration**: Connected to Supabase and Firebase for dynamic content and data management.
*   **Contact Form**: Integrated with Resend for reliable email delivery.

## 🛠️ Tech Stack

*   **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
*   **Library**: [React 19](https://react.dev/)
*   **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
*   **3D Graphics**: [Three.js](https://threejs.org/), [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber/getting-started/introduction), [@react-three/drei](https://github.com/pmndrs/drei)
*   **Animations**: [Framer Motion](https://www.framer.com/motion/), [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)
*   **Icons**: [Lucide React](https://lucide.dev/), [React Icons](https://react-icons.github.io/react-icons/), [Material Icons](https://mui.com/material-ui/material-icons/)
*   **Backend/Database**: [Supabase](https://supabase.com/), [Firebase](https://firebase.google.com/)
*   **Email**: [Resend](https://resend.com/)

## 💻 Getting Started

### Prerequisites

*   Node.js (v18 or higher recommended)
*   npm, yarn, pnpm, or bun

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/space-portofolio-habib.git
    cd space-portofolio-habib
    ```

2.  Install dependencies:
    ```bash
    npm install i
    # or
    yarn install i
    # or
    pnpm install i
    # or
    bun install i
    ```

3.  Set up environment variables:
    *   Create a `.env` or `.env.local` file in the root directory.
    *   Add your Supabase, Firebase, and Resend credentials (refer to `.env.example` if available).

4.  Run the development server:
    ```bash
    npm run dev
    # or
    yarn dev
    # or
    pnpm dev
    # or
    bun dev
    ```

5.  Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📜 Available Scripts
